# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-10-18

### Added
- Initial release
- Support for MCP (Model Context Protocol) integration
- Tool operations: List Tools, Call Tool
- Prompt operations: List Prompts, Get Prompt
- Resource operations: List Resources, Read Resource
- JSON-RPC 2.0 protocol support
- SSL certificate validation bypass option for development
- API key authentication
- Continue on fail support
- Comprehensive error handling
